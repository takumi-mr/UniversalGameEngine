# 麻雀牌の 3D モデル

`apps/frontend/src/three/MahjongUI.ts` がこのディレクトリから牌モデル（glTF バイナリ）を読み込む。
ファイルが無い牌は、牌面を Canvas で手続き描画した箱で代用される（`mahjongTileTexture.ts`）。

## ファイル名

| ファイル                   | 牌                                     |
| -------------------------- | -------------------------------------- |
| `1m.glb` 〜 `9m.glb`       | 萬子                                   |
| `1p.glb` 〜 `9p.glb`       | 筒子                                   |
| `1s.glb` 〜 `9s.glb`       | 索子                                   |
| `1z.glb` 〜 `7z.glb`       | 東・南・西・北・白・發・中             |
| `0m.glb` `0p.glb` `0s.glb` | 赤五（萬・筒・索）                     |
| `back.glb`                 | 裏面（他家の手牌・未公開のドラ表示牌） |

牌の名前は `packages/shared/rules/mahjong/MahjongTiles.ts` の表記（`"1m"`, `"7z"`, `"0p"` …）と同じ。

## モデルの規約

- **立てた状態**でエクスポートする: 牌面が **+Z**、幅が **X**、高さが **Y**、厚みが Z
- 原点の位置とスケールは問わない（読み込み時にバウンディングボックスの中心を原点に寄せ、幅を基準に拡縮する）
- 高さ・厚みの比率は最初に読み込めたモデルから取るので、全牌で同じ寸法にする
- マテリアル・テクスチャはモデルに含めたものがそのまま使われる
